# 🛒 Amazon Home Page Clone

A responsive front-end clone of the Amazon homepage built using HTML5 and modern CSS3 (Flexbox & Grid layout).

---

## 📌 Project Overview

This project was built as a foundational exercise in web development to master layout techniques, navigation bar structures, hero banners, product feature cards, and multi-tier footers based on real-world e-commerce user interfaces.

---

## ⚡ Key Features

- **Multi-Level Navigation Bar**: Features Amazon logo styling, delivery destination selector, search bar with category dropdown, account/orders links, and shopping cart badge.
- **Sub-Navigation Panel**: Category shortcut links and promotional banner.
- **Hero Section**: High-resolution hero banner overlaying grid content.
- **Product Showcase Grid**: Multi-card product section showcasing categories like Health & Care, Gaming Accessories, Home Arrivals, Tech Upgrades, and more.
- **Structured Footer**: Back-to-top action, multi-column navigation menu, Amazon logo footer branding, and legal/copyright panel.
- **Responsive Elements**: Flexible item alignment utilizing CSS Flexbox.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, `<article>`)
- **CSS3**: Custom CSS, Flexbox, Grid, CSS Background Images
- **FontAwesome (v6.7.2)**: UI vector icons for cart, location, search, and hamburger menu

## 🚀 How to Run

1. Clone or download the repository.
2. Open `amazon-clone/index.html` in any web browser (Google Chrome, Firefox, Edge, Safari).
3. Alternatively, launch with live preview tools such as VS Code Live Server.
